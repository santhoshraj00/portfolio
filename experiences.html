Mes expériences

Page Web informative sur les animaux

Dans le cadre d’un projet scolaire, j’ai créé ma première page web en HTML. Ce projet avait pour but de rendre une simple page, mais j’ai rapidement pris goût au développement web. J’ai décidé d’aller plus loin en ajoutant une barre de navigation et en intégrant Bootstrap pour améliorer la présentation. Le site final est une page informative sur les animaux, claire et structurée. Avec l'envie d'aller plus loin, en rendant le site multi-sujets et plus dynamique grâce à JavaScript.

HTML CSS Bootstrap JavaScript

ALSTOM - Gestion du suivi de fabrication

Durant ce stage chez ALSTOM, j’ai pu découvrir pour la première fois le milieu professionnel dans lequel j’ai appris à observer le fonctionnement de l’administration, mais aussi tout le processus nécessaire pour arriver à un produit fini : l’assemblage des produits, l’étiquetage avec des codes-barres sur les produits ou les matériaux, ainsi que le cheminement du produit tout au long de l’entreprise jusqu’à son expédition.

Application de gestion de bibliothèque (C#)

Lors d’un projet scolaire, dans lequel on devait créer une sorte de bibliothèque sur Visual Studio, j’ai conçu une interface graphique avec différents champs liés aux classes que nous avions créées. C’est la première fois que j’ai vu comment créer une interface graphique et la logique qui l’accompagne. Dans ce projet, je pouvais gérer le nombre d’emprunts effectués, les dates de retour et d’emprunt, la gestion du stock, effectuer un tri et enregistrer les retours avec la date correspondante.

C# WinForms Visual Studio
