Projet - SGRC

Contexte

Durant cette deuxième année, nous avions un projet de recoder une application de gestion de restauration. L'objectif était de nous faire travailler en équipe et de concevoir un logiciel en groupe pour avoir une version fonctionnelle de l'application.

Besoin

Les besoins étaient d'avoir une bonne répartition des tâches entre chaque petit groupe pour savoir qui fait quoi, puis de les mettre en commun pour créer petit à petit toutes les interfaces de l'application. Nous avions pour cela besoin d'une API qui centralisait les fonctions pour permettre de faire fonctionner toutes les pages entre elles.

Environnement

Le projet a été développé avec les technologies suivantes :

  • Langages utilisés : PHP, HTML, CSS
  • Framework et outil : Bootstrap
  • Environnement de développement : Visual Studio Code
  • Serveur distant : FileZilla pour le déploiement et la gestion des fichiers
  • Base de données distante : MySQL

Réalisation

  • Première étape de réalisation : Savoir ce que fait chacun en début de semaine et se fixer les objectifs à atteindre en chaque fin de semaine.
  • Deuxième étape de réalisation : Coder les fonctions pour l'API et concevoir les pages pour créer les différentes interfaces du logiciel. Utilisation de FileZilla pour déployer le code sur le serveur distant.
  • Troisième étape de réalisation : Interconnecter chaque page avec l'API et la base de données distante pour que le logiciel fonctionne correctement entre chaque interface.

Bilan

Ce logiciel m'a permis de comprendre comment, dans une grosse équipe, nous pouvions travailler ensemble et cela m'a permis de comprendre que la communication entre développeurs est essentielle à la réussite d'un projet comme celui-là en groupe.
